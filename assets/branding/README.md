# Paw IDE branding

Official brand files, copied **verbatim** from the Paw IDE website (`public/brand/`,
`src/app/`, `brand-source/`). Do not redraw or restyle them.

| File | Variant | Origin |
|------|---------|--------|
| `paw-logo.svg` | Mark only (white paw + `</>`), transparent background | `public/brand/logo.svg` |
| `paw-icon.svg` | Application icon, rounded black tile, no name | `src/app/icon.svg` |
| `paw-icon.ico` | Windows icon (7 sizes) rendered from `paw-icon.svg` | derived |
| `paw-avatar.png` | Avatar with the "PAW IDE" name | `brand-source/paw-ide-avatar.png` |

The intro animation (`brand-source/paw-ide-intro.gif`, `public/brand/intro.mp4|webm`) stays in
the website part of the repository and is fetched by the Asset Manager when needed.
